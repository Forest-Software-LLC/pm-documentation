# pm-documentation

Documentation site for Forest PM (forestpm), the package manager for Roblox and UEFN. Built with Nextra 4 and served as a static export from a Cloudflare Worker at https://docs.forest.dev.

```bash
npm run dev      # local dev server on http://localhost:3003
npm run build    # static export into out/
npm run preview  # serve the export through wrangler dev
npm run deploy   # build and deploy the forest-docs Worker
```
