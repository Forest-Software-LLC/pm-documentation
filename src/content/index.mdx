## How Forest works

Forest is a registry plus a command-line tool. You run `forest` in your project folder, and it installs packages as real files on disk next to a manifest and lockfile that you commit to source control. It is **not** a Roblox Studio plugin: getting the installed files into your game is handled by whatever sync setup you already use, commonly [Rojo](https://rojo.space) on Roblox. See [Forest across platforms](/concepts/intro#forest-across-platforms) for how each platform lays those files out.

Browse [everything Forest can do](/features/intro) in the Features section, jump straight to your platform ([Roblox](/platforms/roblox/intro) or [UEFN](/platforms/uefn/intro)), or read how the [entire package pipeline](/open-source) is open source and independently verifiable.
