# Installing the Forest CLI

The Forest CLI is your entry point into the Forest PM ecosystem. It's a lightweight tool that lets creators and teams manage packages and projects directly from the terminal.

## Quick install

Run the command for your operating system in a terminal:

<Tabs items={['Windows (PowerShell)', 'macOS / Linux']}>
  <Tabs.Tab>
    ```powershell
    irm https://releases.forest.dev/install.ps1 | iex
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    ```bash
    curl -fsSL https://releases.forest.dev/install.sh | sh
    ```
  </Tabs.Tab>
</Tabs>

The installer detects your platform, downloads the latest `forest` binary, **verifies its SHA-256 checksum** against the published release manifest, and adds it to your `PATH`. No admin rights are required; everything installs per-user:

| OS | Install location |
|---|---|
| Windows | `%LOCALAPPDATA%\forest-cli\bin` |
| macOS / Linux | `~/.local/bin` |

Prefer to inspect before running? Both scripts are plain text; open the URLs in your browser first.

## Verify the installation

Open a **new** terminal (so the `PATH` change takes effect) and run:

```bash
forest --version
```

If installed correctly, you'll see the Forest CLI version number.

From then on the CLI keeps itself current: [`forest upgrade`](/forest-cli/commands#forest-upgrade) updates it in place, and a one-line notice appears when a newer release is available.

## Options

<Tabs items={['Windows', 'macOS / Linux']}>
  <Tabs.Tab>
    Download the script first to pass options:

    ```powershell
    # Pin a specific version
    .\install.ps1 -Version v0.1.0

    # Uninstall
    .\install.ps1 -Uninstall
    ```

    Environment overrides: `FOREST_INSTALL_DIR` (install location), `FOREST_INSTALL_BASE` (download mirror).
  </Tabs.Tab>
  <Tabs.Tab>
    ```bash
    # Pin a specific version
    curl -fsSL https://releases.forest.dev/install.sh | FOREST_VERSION=v0.1.0 sh

    # Custom install directory
    curl -fsSL https://releases.forest.dev/install.sh | FOREST_INSTALL_DIR=~/bin sh

    # Uninstall (download first, then run with the flag)
    sh install.sh --uninstall
    ```
  </Tabs.Tab>
</Tabs>

## Supported platforms

| Platform | Architecture |
|---|---|
| Windows | x64 (ARM64 runs the x64 build under emulation) |
| macOS | Apple Silicon & Intel |
| Linux | x64 |

## Install with Rokit

Forest is also available through [Rokit](https://github.com/rojo-rbx/rokit), the Roblox toolchain manager. This lets each project pin its own CLI version:

```bash
rokit add Forest-Software-LLC/forest-cli forest
```

The trailing `forest` names the command. Without it, Rokit installs the tool as `forest-cli`. To pin per project, declare it in `rokit.toml`:

```toml
[tools]
forest = "Forest-Software-LLC/forest-cli@1.13.0"
```

<Callout type="info">
  Under Rokit, versioning belongs to Rokit: `forest upgrade` refuses to run and updates come from `rokit update forest`. Rokit downloads release archives from GitHub rather than through the signed release manifest.
</Callout>
